# Project instructions

- Preserve the Vinext, Vite, Cloudflare Worker, and Sites hosting structure.
- Keep public content in `lib/portfolio.ts` and brand identity in `lib/brand.ts`.
- Keep D1 access server-only and use prepared parameterized statements.
- Never expose secrets, owner controls, or raw errors to client components.
- All new UI must work with keyboard, touch, reduced motion, and 320px widths.
- Run lint, typecheck, tests, and the production build after meaningful changes.
- Update `docs/IMPLEMENTATION_STATUS.md` when a milestone or limitation changes.
