# Accessibility

Target: WCAG 2.2 AA.

- Semantic landmarks, skip link, logical headings, descriptive labels, and live submission status
- Full keyboard access for navigation, filters, dialogs, accordions, forms, and owner controls
- Visible high-contrast focus state and 44px touch targets
- Native dialog semantics and Escape close behavior for the showreel treatment
- Reduced-motion CSS and JavaScript guards
- No autoplay audio; decorative artwork is hidden from assistive technology
- Errors are tied to fields and summarized in plain language
- Mobile content never depends on hover or a custom cursor

Release checks cover 320px width, 200% zoom, keyboard-only use, contrast, reduced motion, and form recovery.
